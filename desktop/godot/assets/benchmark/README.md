# Clovermere benchmark art pack

This directory is the first authored pixel-asset set for Clovermere. It is intentionally limited to the central-crossing benchmark so palette, scale, silhouettes, material boundaries, and contact shadows can be reviewed before the whole procedural world is replaced.

## Palette

The pack uses a restrained pastoral palette: deep forest ink, blue-green shadow, moss and leaf greens, warm clay plaster, dark timber, muted brass, cool glass, and mineral stone. The source of truth is `scripts/art_asset_pack.gd`; the PNGs are generated by `tools/generate_benchmark_assets.py`.

Do not add ad-hoc colours to individual assets. Extend the palette deliberately in the manifest and generator, then review the full benchmark capture in day and evening lighting.

## Regeneration

From the repository root:

```bash
python3 desktop/godot/tools/generate_benchmark_assets.py
godot --headless --editor --quit --path desktop/godot
godot --headless --path desktop/godot --script res://tests/art_asset_pack_test.gd
```

The generator uses only original hand-authored primitives and produces transparent RGBA PNGs. No third-party art, protected names, or external asset packs are used.
